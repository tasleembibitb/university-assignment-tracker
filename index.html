How it works

University assignments pile up — one to send on WhatsApp, one to print, one whose topic still needs confirming. This tracker keeps each assignment with its subject, topic, teacher and due date, plus two checklists: soft copy (sent to the teacher) and hard copy (printed and submitted in class). Your list is saved in your browser, so it is still there tomorrow.

Soft copy vs hard copy

  • Soft copy — send the file to the teacher personally, not in the class group, so nobody copies it.
  • Hard copy — print it and submit it in class.
  • Tick both boxes on the assignment card when each one is done.

Important note

This is a demo tracker. The sample assignments are real subjects and topics only — never put a password, phone number, CNIC number or roll number into a tracker or a public post. Always check with your teacher for the final due date.
